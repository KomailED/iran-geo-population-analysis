# Population of Major Cities in Iran 🇮🇷

This project visualizes the population of major Iranian cities using a geographic scatter plot.

City populations are represented as scaled markers on the map of Iran, allowing for a quick visual comparison of population distribution across the country.

---

## 📌 Project Overview

* Data Source: City population dataset (Excel → CSV)
* Visualization Type: Scatter plot on geographic map
* Tools Used:

  * Python
  * Pandas
  * Matplotlib
  * Basemap

---

## 📊 What This Project Shows

* Geographic distribution of major cities in Iran
* Relative population size using marker scaling
* Clear visual comparison between high and low population cities
